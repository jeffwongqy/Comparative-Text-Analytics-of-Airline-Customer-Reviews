#### _Capstone Project 2021 for Specialist Diploma in Applied Artificial Intelligence_

# Comparative Text Analytics of British Airways and United Airlines Customer Reviews Using Orange


## Project Description
This project applies text analytics techniques to analyze and compare customer reviews from two airline groups. Using Natural Language Processing (NLP), the study performs Sentiment Analysis to evaluate customer opinions, Clustering to discover common discussion themes, and Text Classification to automatically categorize reviews. Power BI is used for data profiling, preprocessing, and exploratory data analysis to ensure data quality and support airline selection. The findings provide insights into customer satisfaction, service quality, and key factors influencing passengers' experiences, enabling meaningful comparisons between the selected airlines.
